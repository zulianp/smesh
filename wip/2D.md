# 2D.md

Planar `TRI3` / `QUAD4` meshes use `spatial_dimension() == 2` and a 2-component point SoA. Shells (`TRISHELL*`, `QUADSHELL*`) live in 3D space and keep 3-component points.

## Contract

- Barycenters and SFC write/read only `d < spatial_dimension()`. Morton/Hilbert encoders stay 3D; `z` is a zero buffer when `sdim < 3`.
- Serial and MPI `extrude` pad planar points to `z = 0` before the 3-corner normal. `TRI3` and `TRISHELL3` extrude to `WEDGE6`; `QUAD4` / `QUADSHELL4` to `HEX8`.
- `CircleParametrization` on `sdim == 2` is an in-plane circle (implicit `+z` axis). `SphereParametrization` and `PolynomialSurfaceParametrization` still require `sdim >= 3`.

## Jacobians / FFF

Native compact packing (not padded 3×3). Same convention as 3D: adjugate is the full matrix, FFF is the symmetric upper triangle.

| | 3D | planar TRI3 / QUAD4 |
|--|--|--|
| Adjugate SoA | 9 | 4 |
| FFF SoA | 6 | 3 |

TRI3 uses the linear map of the three corners. QUAD4 is isoparametric at `(1/2, 1/2)`. `JacobianAdjugateAndDeterminant` / `FFF` buffer sizes follow the element family. TRISHELL / QUADSHELL surface Jacobians (3×2) are not implemented.
